# Student Record Management System

A beginner-friendly Python project that manages student records using SQLite.

## Features

- Add new student records
- View all student records
- Search for a student by ID
- Update existing student details
- Delete student records
- Store data in an SQLite database

## Technologies Used

- Python
- SQLite
- SQL

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

   `python studentrecord.py`

5. Follow the menu displayed in the terminal.

## Learning Outcomes

- Practiced Python programming
- Learned database operations using SQLite
- Used SQL queries to manage records
- Built a menu-driven command-line application
